# Chapter 01 - Basics

## What is this chapter about?

Imagine you just got a brand new toy. Before you can play with it, you need to know how to turn it on and make it do something. That's exactly what this chapter is about - it's your very first step into the world of JavaScript!

## What will you learn?

### 1. How to print something on the screen
You know how you can tell your friend "Hello!" by talking? In JavaScript, we use a special command called `console.log()` to say something on the screen.

```javascript
console.log("Hello The Testing Academy");
```

This is like writing a note and putting it on the screen for everyone to see!

### 2. How to store a value in a variable
Imagine you have a box labeled "x" and you put the number 10 inside it. In JavaScript, we do the same thing with variables!

```javascript
let x = 10;
```

This creates a box called `x` and puts the number `10` inside it. Later, whenever you say `x`, JavaScript knows you mean `10`.

### 3. How to verify your setup
Before you start building big things, you need to make sure your tools are working. This chapter also helps you check that JavaScript is running properly on your computer.

## Files in this chapter

| File | What it does |

## Key Takeaways

- `console.log()` is how JavaScript talks to you
- `let` creates a box (variable) to store things
- Always check your setup before building something big!
