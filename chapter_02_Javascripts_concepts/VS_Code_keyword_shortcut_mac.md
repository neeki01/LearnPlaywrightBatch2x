# Visual Studio Code Keyboard Shortcuts (macOS)

## Basic Editing

| Shortcut | Action |
|----------|--------|
| `Cmd + C` | Copy |
| `Cmd + X` | Cut |
| `Cmd + V` | Paste |
| `Cmd + Z` | Undo |
| `Cmd + Shift + Z` | Redo |
| `Cmd + S` | Save |
| `Cmd + A` | Select All |
| `Cmd + /` | Toggle Line Comment |
| `Cmd + Option + /` | Toggle Block Comment |
| `Cmd + D` | Select Next Occurrence |
| `Cmd + Shift + L` | Select All Occurrences |
| `Cmd + Shift + K` | Delete Line |
| `Cmd + Enter` | Insert Line Below |
| `Cmd + Shift + Enter` | Insert Line Above |
| `Option + Up/Down` | Move Line Up/Down |
| `Shift + Option + Up/Down` | Copy Line Up/Down |
| `Cmd + ]` | Indent Line |
| `Cmd + [` | Outdent Line |
| `Cmd + Left` | Go to Beginning of Line |
| `Cmd + Right` | Go to End of Line |
| `Cmd + Up` | Go to Top of File |
| `Cmd + Down` | Go to Bottom of File |
