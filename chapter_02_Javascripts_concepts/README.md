# Chapter 02 - JavaScript Concepts

## What is this chapter about?

Imagine you're learning to ride a bicycle. First, you need to know the parts of the bicycle - the handlebars, pedals, and brakes. This chapter is like learning the parts of JavaScript! It teaches you the basic building blocks that everything else is made from.

## What will you learn?

### 1. JavaScript Basics
Just like you use words to make sentences, JavaScript has its own words to give instructions. You'll learn how to store a number in a variable, change it, and show it on the screen.

```javascript
let v = 10;
console.log(v);
v = 13;
console.log(v);
```

This is like having a box labeled "v". First you put 10 in it, then you take out 10 and put 13 in its place. The box always shows what's inside!

### 2. Comments - Notes for Humans
Sometimes you want to leave notes in your code so that you (or your friends) can understand what the code does later. Comments are like sticky notes in your code - JavaScript ignores them completely!

```javascript
// This is a comment - JavaScript will skip this line
let age = 25; // You can also put comments at the end of a line
```

### 3. VS Code Shortcuts
This chapter also includes helpful keyboard shortcuts for VS Code (the code editor). These shortcuts are like cheat codes in a video game - they help you work faster!

## Key Takeaways

- Variables are like boxes that hold values
- You can change what's inside a variable (that's why it's called "variable"!)
- Comments help humans understand code but are invisible to JavaScript
- Learning keyboard shortcuts makes you super fast!

## Real World Connection

Think of comments like labels on your lunch box. You write "Mom's yummy sandwich" so you know what's inside. Comments do the same thing for code - they tell programmers what the code does without changing how it works.
