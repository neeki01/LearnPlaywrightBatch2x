# Problems Solved as Tasks

## What is this folder about?

This folder is like a PRACTICE GROUND! It contains real coding challenges and problems that combine everything you've learned from all the chapters. These are the kinds of questions asked in interviews and used in real testing scenarios.

## What will you learn?

### 1. Exam.js - Testing Challenges
This file contains real-world QA (Quality Assurance) challenges:

**Challenge 1: API Response Handler**
Uses `switch` statement to handle different HTTP status codes (200, 404, 500, etc.) and give appropriate messages.

**Challenge 2: Test Case Result Counter**
Counts pass, fail, and skip results from an array, calculates pass rate, and gives a verdict (ready for release / review required / block release).

**Challenge 3: Retry Logic with API Calls**
Simulates an API call that might fail, and retries up to 5 times. Uses `do-while` loop to keep trying until success.

**Challenge 4: Element State Evaluator**
Determines the state of a web element (READY, HIDDEN, DISABLED, NOT FOUND) and suggests actions based on severity. Uses ternary operators and switch statements.

### 2. PatternPy.js - Pattern Printing
Learn to draw patterns using nested loops:

**Pattern 1: Decreasing Stars**
```
*****
****
***
**
*
```

**Pattern 2: Pyramid**
```
  *
 ***
*****
```

These patterns teach you how to use nested loops and control spacing - great for building logic skills!

### 3. ProblemsOnLoops.js - Logic Building
**Triangle Classifier:**
Given three sides, determine if a triangle is equilateral, isosceles, or scalene using if-else.

**FizzBuzz:**
Print numbers 1-100. For multiples of 3, print "Fizz". For multiples of 5, print "Buzz". For both, print "FizzBuzz". This is a CLASSIC interview question!

### 4. StringProblems.js - String Manipulation
**Palindrome Check:**
Reverse a string and check if it reads the same forwards and backwards (like "Madam").

**Anagram Check:**
Check if two strings have the same characters (like "pot" and "top").

## Files in this folder

## Key Takeaways

- Real interview questions combine multiple concepts (loops + if-else + arrays)
- Pattern printing builds strong logic and nested loop understanding
- FizzBuzz tests your ability to handle multiple conditions
- String problems teach you to manipulate text programmatically
- API-related problems prepare you for real QA/testing scenarios
- Always break complex problems into smaller steps
